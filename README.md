# Iconicgirls · Landing Page

Landing page de Iconicgirls (moda que resalta tu esencia), desempaquetada del HTML único original.

- `index.html`: la página
- `assets/`: imágenes, fuentes y runtime

Notas:
- React se carga desde jsDelivr (CDN), así que necesita internet.
- Las fuentes de Allura, Montserrat y Playfair Display están bajo licencia SIL OFL 1.1 (Google Fonts).
- Para verla en GitHub Pages: Settings → Pages → rama `main`, carpeta `/ (root)`.
